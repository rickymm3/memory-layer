Connect your IDE

Add memoryLayer to your IDE by pasting the config below. Replace YOUR_TOKEN with your API token above.

VS Code .vscode/mcp.json

{
  "servers": {
    "memoryLayer": {
      "type": "sse",
      "url": "{{ request.host_url }}mcp/sse",
      "headers": {
        "Authorization": "Bearer {{ current_user.api_token }}"
      }
    }
  }
}

Claude Desktop claude_desktop_config.json

Config file location: ~/Library/Application Support/Claude/ (Mac)  ·  %APPDATA%\Claude\ (Windows) 

{
  "mcpServers": {
    "memoryLayer": {
      "command": "npx",
      "args": ["-y", "memory-layer"],
      "env": {
        "MEMORY_LAYER_TOKEN": "{{ current_user.api_token }}",
        "MEMORY_LAYER_URL": "{{ request.host_url }}mcp/sse"
      }
    }
  }
}
Windows + WSL (if you get spawn npx ENOENT)
Claude Desktop on Windows doesn't inherit your WSL Node/npx. Use wsl.exe (always available in Windows PATH) to run npx from inside WSL instead. WSLENV forwards the token and URL into the Linux environment. 
{
  "mcpServers": {
    "memoryLayer": {
      "command": "wsl",
      "args": ["-e", "bash", "-lc", "npx -y memory-layer"],
      "env": {
        "MEMORY_LAYER_TOKEN": "{{ current_user.api_token }}",
        "MEMORY_LAYER_URL": "{{ request.host_url }}mcp/sse",
        "WSLENV": "MEMORY_LAYER_TOKEN/u:MEMORY_LAYER_URL/u"
      }
    }
  }
}

Verify the server is reachable first: run curl http://localhost:5000/ in your WSL terminal.

Local self-hosted (stdio)

Running memory-layer locally? Use the stdio transport with your local .env file — no token needed. 

{
  "servers": {
    "memoryLayer": {
      "type": "stdio",
      "command": "/path/to/.venv/bin/python",
      "args": ["-m", "mcp_server.server"],
      "envFile": "/path/to/memory-layer/.env"
    }
  }
}

Claude Code skills

Skills extend Claude Code with Synapse-aware slash commands. Save each file to .claude/skills/<name>/SKILL.md in your project (or globally at ~/.claude/skills/<name>/SKILL.md), then use the command in any session.

/synapse:push — push a conversation to memory

Extracts memory atoms from the current or a past session and queues post drafts. Save to .claude/skills/push/SKILL.md.

/synapse:recall — search past memory

Searches your memory atoms for past decisions, preferences, and context. Save to .claude/skills/recall/SKILL.md.
